# iPad で使うための手順（日本語版 OpenCut）

このリポジトリは [opencut-classic](https://github.com/opencut-app/opencut-classic) をもとに、次の点を変更したものです。

- 画面を日本語化（右上の「EN / 日本語」ボタンで英語に切り替え可能）
- iPad のタッチ操作に対応（タイムラインのクリップ移動・長さ調整・再生ヘッド・キーフレーム・カラーピッカー）
- iPad で「デスクトップ専用」の警告を出さないように変更
- 文字起こしは iPad では軽量モデル（whisper-tiny）を使用
- 公式サービスへの利用状況の送信（解析スクリプト）とフィードバック送信を削除

iPad では開発用サーバーを動かせないので、**インターネット上に公開してから** iPad の Safari で開きます。
公開には無料の [Vercel](https://vercel.com) を使います。

## 1. Vercel に公開する（初回のみ・約 10 分）

パソコンでも iPad の Safari でも作業できます。

1. https://vercel.com/signup を開き、「Continue with GitHub」で GitHub アカウントを使って登録します（Hobby プラン＝無料）。
2. ダッシュボードで「Add New…」→「Project」を選びます。
3. リポジトリ一覧から `cut-video` の「Import」を押します。表示されない場合は「Adjust GitHub App Permissions」から `cut-video` へのアクセスを許可します。
4. 設定画面で次のように指定します。
   - **Root Directory**: 「Edit」を押して `apps/web` を選ぶ
   - **Framework Preset**: Next.js（自動で選ばれます）
   - 環境変数（Environment Variables）は**何も入力しなくて大丈夫です**
5. 公開されるのはリポジトリの既定ブランチです。別のブランチを公開したい場合は、公開後に「Settings」→「Git」→「Production Branch」でブランチ名を指定します。
6. 「Deploy」を押し、数分待ちます。
7. 完了すると `https://cut-video-xxxx.vercel.app` のような URL が表示されます。これがあなた専用の OpenCut です。

以降は、GitHub のブランチを更新すると自動的に公開内容も更新されます。

## 2. iPad で開く

1. iPad の **Safari** で、上の URL の末尾に `/projects` を付けて開きます。
2. 共有ボタン →「**ホーム画面に追加**」を選びます。
   - アプリのように全画面で使えます。
   - Safari のタブで開いたまま使うより、作ったプロジェクトが消えにくくなります（Safari は長期間使わないサイトのデータを削除することがあります）。
3. ホーム画面のアイコンから起動します。
4. 「プロジェクトを失わないために」というダイアログが出たら「許可する」を選びます。

## 3. 使い方のコツ

- **iPad は横向き**で使ってください。縦向きだと画面が窮屈です。
- **iPadOS は最新版**にしてください。古い iPadOS だとプレビューが表示されなかったり、遅かったりすることがあります。
  画面上部に「GPU による描画が使えません」と表示された場合も、iPadOS の更新で改善する場合があります。
- 素材の追加：左の素材パネルで「読み込む」をタップし、写真ライブラリやファイルから選びます。素材の右下に出る「＋」をタップすると、タイムラインに追加されます。
- クリップの移動：タイムライン上のクリップを指でドラッグします。
- 長さの調整：クリップの左端・右端をドラッグします。
- メニュー：クリップを**長押し**すると、分割・複製・削除などのメニューが出ます。
- 再生位置の移動：タイムライン上部の目盛りをタップ、またはドラッグします。
- タイムラインのスクロール：クリップのない部分を指でスワイプします。
- Apple Pencil やトラックパッド付きキーボードでも操作できます。キーボードをつなぐと、ショートカット（スペースで再生など）も使えます。

## 4. 8GB 前後のメモリ・iPad で軽く使うために

- 素材は **1080p 以下**の動画がおすすめです。iPhone で撮った 4K / HDR（HEVC）の動画は重く、プレビューできない場合があります。その場合は 1080p の H.264（MP4）に変換してから読み込んでください。これから撮影する動画は、iPhone の「設定」→「カメラ」→「フォーマット」で「互換性優先」にしておくと扱いやすくなります。
- プロジェクトの解像度は 1080p（設定 → 縦横比）までにしてください。
- 他のアプリやタブは閉じておきましょう。
- 文字起こし（字幕 → 文字起こしを開始）は、初回に音声認識モデルをダウンロードします。Wi‑Fi につないで実行してください。軽量モデルのため、英語に比べて日本語の精度は控えめです。

## 5. 使えない機能

公式サーバーが必要な次の機能は、この公開版では使えません。

- 「サウンド」タブの効果音検索（Freesound の API キーが必要です。Vercel の環境変数に `FREESOUND_CLIENT_ID` と `FREESOUND_API_KEY` を設定すると使えます）
- アカウント登録・ログイン
- ブログ・お知らせページ

動画の編集・書き出し・文字起こし・ステッカー・エフェクトは、すべて iPad の中で処理されます。動画がサーバーに送られることはありません。
